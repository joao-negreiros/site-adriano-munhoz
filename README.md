# Adriano Munhoz

Site em HTML/CSS/JS puro, página única (`index.html`).

## Como visualizar

```bash
python -m http.server 8000
```

e acesse `http://localhost:8000`.

## Estrutura

```
index.html      → Página principal
css/styles.css  → Estilos
js/main.js      → Scripts
assets/         → Imagens e outros arquivos estáticos
```
